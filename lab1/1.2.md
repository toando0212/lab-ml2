# 1.2 Data Issues & Preparation (First 10 Dimensions)

Analysis focusing strictly on the first 10 columns (`id`, `diagnosis`, and 8 features):

## 1. What are the issues lying within data?

### Missing Data (Dữ liệu bị thiếu)
*   **Status:** There are **NO missing values** (Nulls) in these 10 columns.
*   *(Note: The `Unnamed: 32` garbage column is outside this scope).*

### Irrelevant Features & Format Issues
*   **`id` column**: This is a unique patient identifier. It contains no biological information and should not be used for prediction (Irrelevant).

### Data requiring Transformation (Dữ liệu cần chuyển đổi)
*   **`diagnosis` column**: This is the **Target Label** (Good/Bad data).
    *   **Status**: **Correct**. It accurately indicates Malignant (M) or Benign (B).
    *   **Action Needed**: Encoding. Machine Learning models require numbers (1/0), not text ('M'/'B'). This is a formatting step, not a data correction step.

### Feature Scaling Disparity (Chênh lệch thang đo)
*   **Issue:** Even within the first 10 columns, scales vary significantly.
    *   `area_mean`: Max value ~2501.
    *   `concavity_mean`: Max value ~0.42.
    *   **Impact:** Algorithms will biased towards `area_mean`.

---

## 2. Do you need to prepare data?

**YES**, preparation is required:

1.  **Drop Irrelevant Features**: Remove `id` column.
2.  **Encode Target**: Convert `diagnosis` to binary (1/0).
3.  **Feature Scaling**: Apply Normalization/Standardization to the 8 numeric features (`radius`...`concave points`) to ensure balanced weights.
