# 1.1 Study the dataset

**Dataset Chosen**: Wisconsin Breast Cancer Diagnostic Dataset

## Feature Analysis (First 10 Dimensions)

Below is the classification justification for the first 10 features:

| # | Feature Name | Type | Quantitative/Qualitative | Numerical/Categorical | Explanation |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 1 | **id** | Discrete | Qualitative | Categorical (Nominal) | It is **Qualitative/Categorical** because it is just a label used to identify a record and has no mathematical meaning. It is **Discrete** because you cannot have an ID like 842302.5; it's a distinct integer code. |
| 2 | **diagnosis** | Discrete | Qualitative | Categorical (Nominal) | It is **Qualitative/Categorical** because 'M' and 'B' described a quality (malignancy status), not a quantity. It is **Discrete** because the values are distinct categories with no intermediate states. |
| 3 | **radius_mean** | Continuous | Quantitative | Numerical (Ratio) | It is **Quantitative/Numerical** because it measures a physical magnitude (length). It is **Continuous** because length can theoretically take any value on the real number line (e.g., 17.99, 17.991...). |
| 4 | **texture_mean** | Continuous | Quantitative | Numerical (Ratio) | It is **Quantitative/Numerical** because it's a calculated standard deviation value representing variation. It is **Continuous** because standard deviation is a real number that can be measured to arbitrary precision. |
| 5 | **perimeter_mean** | Continuous | Quantitative | Numerical (Ratio) | It is **Quantitative/Numerical** as it measures size. It is **Continuous** because perimeter is a physical dimension that isn't restricted to whole numbers. |
| 6 | **area_mean** | Continuous | Quantitative | Numerical (Ratio) | It is **Quantitative/Numerical** as it measures a physical space. It is **Continuous** because area is a product of continuous lengths, resulting in real-valued measurements. |
| 7 | **smoothness_mean** | Continuous | Quantitative | Numerical (Ratio) | It is **Quantitative/Numerical** because it quantifies a specific property (local variation). It is **Continuous** because it's a mean value calculated from real numbers, allowing for decimals. |
| 8 | **compactness_mean** | Continuous | Quantitative | Numerical (Ratio) | It is **Quantitative/Numerical** because it is a mathematical formula derived from physical dimensions. It is **Continuous** because the result of the formula (perimeter^2 / area) is a real number. |
| 9 | **concavity_mean** | Continuous | Quantitative | Numerical (Ratio) | It is **Quantitative/Numerical** as it measures the severity of a contour. It is **Continuous** because it's a mean value that can take any fractional value. |
| 10 | **concave points_mean** | Continuous | Quantitative | Numerical (Ratio) | It is **Quantitative/Numerical** because it counts and averages specific points. It is **Continuous** because while points are discrete, the *mean* of those points across a sample is a real number (e.g., 0.1471), not an integer. |

### Summary
*   **Categorical Features**: `id`, `diagnosis` (Labels or Categories)
*   **Continuous Features**: All other measurement columns (Real-valued measurements allow for infinite precision unlike integer counts).
