# 1.2 Phân tích vấn đề dữ liệu (Data Issues Analysis)

**Dataset**: WineQT.csv  
**Phạm vi**: 11 đặc trưng (features) + 1 cột target (`quality`)

## Kết quả phân tích chi tiết

### Missing Data (Dữ liệu thiếu)
* **Status**: **KHÔNG có** giá trị thiếu (missing values) trong toàn bộ dataset.
* **Kết luận**: Không cần xử lý missing data (imputation).

### Duplicate Rows (Dòng trùng lặp)
* **Status**: **KHÔNG có** dòng dữ liệu trùng lặp.
* **Kết luận**: Không cần loại bỏ duplicates.

### Data Types (Kiểu dữ liệu)
* **Target column** (`quality`):
  * Kiểu: Integer (int64)
  * Giá trị: Các mức điểm 3, 4, 5, 6, 7, 8.
  * **Status**: Hợp lệ. Có thể coi là bài toán phân loại (Classification) hoặc hồi quy (Regression).
  
* **Feature columns** (11 đặc trưng hóa lý):
  * **Tất cả** đều là kiểu số thực (float64).
  * **Status**: Dữ liệu đã ở dạng số, **không cần encoding** (mã hóa).

### Feature Scaling (Chuẩn hóa thang đo)
* **Vấn đề**: Các đặc trưng có thang đo khác nhau đáng kể.
  * `total sulfur dioxide`: Max = 289.0
  * `chlorides`: Max = 0.611
  * `density`: Max = 1.00369
* **Khuyến nghị**: **BẮT BUỘC** phải chuẩn hóa (scaling) trước khi training model, đặc biệt là với PCA.
  * Phương pháp: StandardScaler (chuẩn hóa về Mean=0, Std=1).

## Tóm tắt các bước chuẩn bị dữ liệu (Data Prep Plan)

1. ✅ **Drop Columns**: Loại bỏ cột `Id` (metadata vô nghĩa).
2. ✅ **Clean Data**: Không cần xử lý null/duplicates.
3. ✅ **Encoding**: Không cần (tất cả đều numeric).
4. ⚠️ **Scaling**: Áp dụng StandardScaler cho 11 đặc trưng input.
