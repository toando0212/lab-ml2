\section{Introduction}
This report documents the course project for traffic sign classification. The primary motivation of this project is to apply theoretical knowledge of \textbf{Data Mining} and \textbf{Machine Learning} to a practical image classification task \cite{svm}. By leveraging pre-trained deep learning architectures, we aim to extract high-quality features and perform classification using Support Vector Machines (SVM).

\section{Project Objectives}
The primary objective of this project is to develop an efficient pipeline for traffic sign classification using the GTSRB dataset \cite{gtsrb}. The work initially focuses on feature representation, where ResNet50 \cite{resnet} and InceptionV3 \cite{inception} architectures are employed to transform raw images into high-dimensional feature vectors. Subsequently, data exploration is performed using dimensionality reduction techniques such as PCA and UMAP \cite{umap} to evaluate the separability of these features. Finally, we optimize classification performance by comparing various SVM strategies, including linear approximation via Stochastic Gradient Descent (SGD) for computational efficiency and Non-linear RBF kernels for achieving maximum predictive accuracy.

Through this project, we demonstrate the end-to-end process of data processing, feature engineering, model training, and performance evaluation in a course-based project environment.
